# Tiếng Anh 1 · Global Success – Bài giảng tương tác

Trang chủ: `index.html` (mục lục 16 bài, chia Học kỳ 1 / Học kỳ 2).

- `unit-N.html`: bài giảng từng Unit (3 tiết + tab Luyện nghe).
- `assets/unit-N/`: ảnh và âm thanh của bài đó (trang chỉ tải khi cần). Luôn giữ thư mục này đi kèm `unit-N.html`.
- `phieu-bai-tap/unit-N/`: phiếu bài tập PDF (lesson-1/2/3, dap-an).
- `images/`: ảnh bìa trên trang chủ.

Thêm bài mới: chép `unit-N.html`, thư mục `assets/unit-N/` (và phiếu nếu có) vào đây, cập nhật `index.html`, rồi commit + push.
